Add index to product related models.

This module is designed to optimize database queries by adding indexes
to product-related models. It improves query performance, especially for
large datasets, by reducing the time required to retrieve data.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_
